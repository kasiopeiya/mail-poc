# 本プロジェクトの概要

- メール配信基盤を作成するPoC
- 利用者は社内のメール配信を行いたいシステムで、メール配信基盤はバックエンドAPIを用意してメール送信のリクエストを受け付ける

# 目的

- メール配信やAmazon SESの仕様や機能を理解すること
- 実際のプロジェクト開始前に落とし穴や重要な論点を把握すること

# 主な要件

- メール配信基盤は複数のメール配信サービスを利用する（SES・SendGridなど）
- 最初の利用システムはSESを使用するので、まずはSESだけで始めるが、今後の拡張性を考慮する必要がある
- 利用者は利用するメールサービスの選定をしなくても良いインターフェースにする（IFは抽象化し、どのメール配信サービスを使うべきかのロジックを基盤側で持つ）
- 自前の抑止リストを持つ
- PoCのため費用を最小限に抑える
- ドメイン認証などリアルな設定を実施する、必要であればSESのサンドボックス解除も申請する

# 想定利用システム

- 登録完了メールのような通知に利用予定、広告などではない

# その他

- ドメインはRoute53で取得予定（.linkなど安いものを使う想定）
