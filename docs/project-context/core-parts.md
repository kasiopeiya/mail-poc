# このプロジェクトのコア部分

このシステムの中核——**壊れると全体が回らなくなる部分**を、人間が一度だけ名指しした一覧。AI は重要性を自分で判断せず、この一覧と照合するだけにする。照合は「何が中核か」の記述で行い、「主な場所」は現物を探す手がかりとして使う。

使うのは `docs/policy/adr-policy.md` の判定である（この一覧に載った部分の決定は、後から「なぜ」と問われやすいので ADR の候補になる）。

> [!NOTE]
> このファイルはテンプレート同期の対象外なので、書き換えてもテンプレート側の更新で戻らない。

| コア部分 | 何が中核か                                                                         | 主な場所 |
| -------- | ---------------------------------------------------------------------------------- | -------- |
| アプリ   | 送信リクエストの受付・配信サービスの判定・メール送信・抑止リストの照合を行うコード | `app/`   |
| インフラ | アプリを動かす AWS リソース（Lambda・SQS・S3・SES など）の定義                     | `infra/` |
