# 仕分け台帳：メール配信基盤 PoC

要件定義書（[docs/requirements.md](../requirements.md)）を書く・レビューする人と AI が、入力資料の各記述を要件定義書のどこへ振ったかを照合するために読む。列と `仕分け` の値の正典は Rule [requirements-doc.md](../../.claude/rule-bodies/requirements-doc.md) の「仕分け台帳」である。

> [!NOTE]
> この台帳固有の判断は次のとおり。
>
> - 入力資料の箇条書き1つ・表の1行を1行にする。1つの記述が複数の項目に入ったときは、`行き先` に `, ` で区切って並べる
> - 1つの記述に、採用する部分とスコープ外にする部分が混ざるときは、行を割る（TR-07・TR-08）
> - 入力資料の冒頭にある対象読者の一文は、要求の記述でないので行にしない
