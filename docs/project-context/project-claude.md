# プロジェクト固有情報

## このシステムは何か

社内向けのメール配信基盤を作る PoC。利用者は、メールを送りたい社内のシステムである。送るのは登録完了メールのような通知で、広告は送らない。

PoC の目的は次の2つ。

- メール配信と Amazon SES の仕様・機能を理解する
- 本番のプロジェクトを始める前に、落とし穴と重要な論点をつかむ

## 固有ドキュメントの置き場所
